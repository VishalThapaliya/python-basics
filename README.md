# 🐍 Python Basics
A beginner-friendly Python learning repository containing notes, examples, exercises, 
and mini-projects as I learn Python step by step.

The goal of this repository is not just to read about Python, but to **practice Python by writing code, making mistakes, 
debugging them, and building small projects.**

## 📚 Learning Roadmap
The repository is organized into learning days. Each day focuses on a specific Python topic and contains small lab 
exercises.

| Topic | What You'll Learn |
|---------|-------------------|
| Python Fundamentals | Python syntax, keywords, variables, basic operations |
| Strings | Strings, indexing, slicing, concatenation, string methods |
| Conditions & Input | input(), if, elif, else, comparisons |
| Python Data & Functions | Lists, tuples, sets, dictionaries, lambda, recursion |
| Object-Oriented Programming | Classes, objects, constructors, inheritance |
| Exceptions | try, except, else, finally, common exceptions |
| Modules	| Importing modules, creating custom modules |
| File I/O | Reading, writing, appending, and working with files |
| Project Structure | Organizing Python programs and combining concepts |
| Debugging | Finding, understanding, and fixing errors |
| Mini Projects | Small projects that combine the concepts learned |

> Note: This repository is a work in progress. New topics and exercises will be added as I continue learning Python.

## 🛠️ Recommended Setup
You can run these exercises using any Python-compatible development environment.

Recommended tools:

Python 3
VS Code, PyCharm, or another Python editor
Git
GitHub
Check that Python is installed:

```commandline
python --version
```

Depending on your operating system, you may need:
```commandline
python3 --version
```
## ▶️ Running the Code
Clone the repository:

```commandline
git clone https://github.com/VishalThapaliya/python-basics.git
```
Move into the repository:
```
cd python-basics
```
Run a Python file:

```commandline
python day_01/lab_001.py
```

On systems where Python 3 uses the python3 command:
```commandline
python3 day_01/lab_001.py
```
